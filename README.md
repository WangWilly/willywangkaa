# WillyWangkaa Blog

## :warning: ARCHIVED PROJECT :warning:

This repository contains an archived personal blog focused on computer science, data structures, algorithms, operating systems, and other technical content.

## About

This blog was built using [Hexo](https://hexo.io/) with the [NexT Pisces](https://theme-next.js.org/) theme. It served as a platform to document and share knowledge on various programming and computer science topics including:

- Data structures (Heap, Binary Search Tree, Graph, etc.)
- Algorithms and sorting techniques
- Operating systems concepts
- File management
- Technical patents

## Technologies

- **Framework**: Hexo
- **Theme**: NexT.Pisces v6.0.4
- **Math Rendering**: MathJax
- **Search**: Local search implementation
- **Comments**: Disqus

## Content Structure

The content is organized by categories and tags, covering topics related to computer science education and research. The blog contains posts in Traditional Chinese and English.
